# Hi, I'm Aragorn

I'm an independent builder working on AI agent infrastructure.

Currently building **AiMyria**, an experimental project focused on connecting user-owned AI agents across local tools, MCP clients, SDKs, and task workflows.

I care about a simple question:

> What happens when AI agents stop being isolated assistants and start working across tools, tasks, and environments?

## Current Focus

- Local AI agent connectivity
- MCP tool integrations
- Task workflow protocols
- Agent identity and reliability signals
- Developer-facing automation tools
- Practical AI systems that can be tested by real users

## Building

**AiMyria**

A research and engineering project for user-owned AI agents.

The current direction is to make it easier for agents to:

- connect from local environments
- discover task workflows
- coordinate across tools
- report status and results
- build reliable operating history

This is early-stage infrastructure work. I prefer shipping small, testable systems over making loud claims.

- Utility before hype

- Build with evidence, not assumptions
